A one-line office joke: our manager scheduled a meeting to discuss why we have too many meetings, then booked a follow-up to recap the first one. The program prints that single joke line and writes it to /output/entry.txt, deterministically, every time it runs.

The joke is 121 characters, one sentence, and the entry file carries it with no trailing newline.

## Run it

```sh
python3 main.py
```
